Privacy Policy

Effective date: October 21, 2026 · Chrome extension version 0.3.4

中文 · Contact / support

Purpose and local processing

URL Loupe highlights non-ASCII and visually similar hostname characters. The extension processes the current tab URL when you open its toolbar popup, URLs you type or paste into the popup or the “host” omnibox mode, the destination of a webpage link when you hover or focus it, and the link URL, explicitly selected URL text or page URL when you choose the right-click inspection menu. Processing takes place locally in your browser. Hostname extraction may temporarily handle a full URL in memory, including any credentials, path or query you supplied; those components are not included in the hostname result. Omnibox and right-click review pages receive only the extracted hostname.

Data collection, storage and sharing

The extension does not transmit browsing URLs, link destinations, page contents, credentials or inspection results to the developer or any third party. It has no account, analytics, advertising, tracking or extension data storage. It does not scan or store browsing history, read form fields, or collect page text beyond the text you explicitly select for a right-click inspection. It listens for link hover and focus events rather than crawling all links. Temporary inspection state is replaced when another URL is checked or the extension context closes. There is no server-side extension dataset to retain or delete.

Permissions and code

“contextMenus” adds the right-click inspection entry. The menu processes the selected URL or actual link destination only when you choose it. “activeTab” allows reading the active page URL after you click the extension icon. Content scripts on HTTP(S) pages inspect hovered or focused link destinations and display a local overlay. The “host” keyword enables opt-in address-bar inspection. The extension does not replace links, intercept clicks, block navigation or visit an inspected URL. All JavaScript, Punycode code and Unicode mappings are bundled in the extension; no remotely hosted code is loaded.

External links and website hosting

Opening the privacy policy, support page or source repository is an ordinary browser navigation you initiate. Those websites and their hosting providers may process normal request metadata, such as IP address, time, requested page and browser information. The website at loupe.zhaidewei.com is hosted on Cloudflare. These visits are separate from the extension’s local URL inspections. If you voluntarily open a GitHub issue, the information you submit is handled by GitHub and may be public; do not include sensitive information.

Limited Use and changes

URL Loupe’s use of information received from Google APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Data accessed through Chrome APIs is used solely to provide the hostname inspection feature. Future changes to data practices will be reflected in this policy and the relevant store disclosures.

Contact

Maintainer: Dewei Zhai. Questions or requests: URL Loupe GitHub Issues. The extension’s local-only processing does not establish whether a website is safe.

隐私政策

生效日期：2026 年 10 月 21 日 · Chrome 插件版本 0.3.4

用途与本地处理

URL Loupe 标记域名中的非 ASCII 与视觉相似字符。点击插件图标后，它读取当前标签页网址；也处理你在面板或 host 地址栏模式中输入的网址，以及悬停或聚焦链接时的目标地址。主动选择右键检查菜单时，会处理真实链接目标、明确选中的网址文本或当前页面网址。分析在浏览器本地完成。解析过程可能短暂在内存中处理完整网址及其中的身份信息、路径和参数；这些内容不会进入域名结果。地址栏与右键打开的检查页只接收解析后的 host。

收集、存储与共享

插件不向开发者或第三方发送浏览网址、链接目标、页面内容、身份信息或检查结果。没有账号、统计、广告、跟踪或插件数据持久化存储；不扫描或保存浏览历史，不读取表单，除主动选中并右键检查的文本外，不收集页面文本。它监听链接悬停和聚焦事件，不批量抓取页面链接。临时检查状态在检查其他网址或插件上下文关闭时替换或释放，因此没有服务端插件数据可保留或删除。

权限与代码

contextMenus 用于添加右键检查菜单，仅在主动选择菜单后处理所选网址或真实链接目标；activeTab 用于点击图标后读取当前网址；HTTP(S) 页面的 content scripts 用于检查悬停或聚焦链接并显示本地浮层；host 关键字提供主动进入的地址栏检查。插件不替换链接、不接管点击、不阻止跳转、不访问被检查的网址。JavaScript、Punycode 和 Unicode 映射随插件打包，不执行远程代码。

外部链接与托管

主动打开隐私政策、帮助或源码属于普通网页访问，相应网站及托管方可能处理 IP、访问时间、页面和浏览器信息等常规请求元数据。本网站由 Cloudflare 托管；这些访问与插件的本地网址检查相互独立。主动提交 GitHub Issue 的内容由 GitHub 处理，可能公开，请勿包含敏感信息。

有限使用、更新与联系

通过 Google API 获取的信息遵守 Chrome Web Store 用户数据政策及 Limited Use 要求，仅用于提供域名检查功能。若数据处理方式变化，将同步更新政策与商店披露。维护者：Dewei Zhai；联系渠道：GitHub Issues。字符提示不构成网站安全判定。
