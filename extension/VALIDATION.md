## 重跑

核心测试无需安装依赖：

```sh
node --test tests/*.test.cjs
```

浏览器验证脚本为 `tests/browser.cjs`。需要在隔离测试环境准备 Playwright 和 Chromium。脚本通过 `PLAYWRIGHT_MODULE` 可指定已有 Playwright 模块，通过 `PLAYWRIGHT_BROWSERS_PATH` 可指定测试浏览器安装位置。脚本使用独立临时配置并在退出时删除该配置，不使用日常 Chrome 资料。

```sh
node tests/browser.cjs
```

浏览器截图默认写入扩展目录的父目录，可通过 `HOST_LENS_ARTIFACTS` 指定已有目录。
