NAME
URL Loupe

SHORT DESCRIPTION
Inspect non-ASCII hostnames and brand lookalikes locally. Right-click links, use the toolbar or type host + Tab.

DETAILED DESCRIPTION
A closer look at every URL.

URL Loupe explains the parts of a hostname worth checking. All non-ASCII characters are highlighted. When a hostname resembles a reference brand, only the actual differences are marked, such as rn instead of m or a different domain suffix. Ordinary English letters are not highlighted just because they could look like another character.

Three ways to inspect:
• Right-click a link, selected URL or page and choose “Inspect with URL Loupe”. The native toolbar popup opens while the webpage stays active. The actual link destination is checked, even if its visible text differs.
• Open the toolbar popup to inspect the current tab or paste a URL for instant results. Bare domains such as example.com also work.
• Type host, press Tab in Chrome’s address bar, and enter a URL. Enter opens a local review page.

Pink marks non-ASCII characters. Gold marks brand differences. Focus, hover or click a highlighted character to connect it with its explanation. Expand Check details for ASCII/Punycode and character information.

An exact match in the 6,890-host reference set suppresses generic ASCII hints. Brand comparison uses references for 671 companies and manually sourced brand aliases. The Google CrUX September 2026 Top 5,000 origin buckets contribute exact hostname references, not additional fuzzy-brand targets. CrUX data is attributed under CC BY 4.0. This independent project is not endorsed by Google.

Inspection runs locally with bundled code and data. Only activeTab and contextMenus permissions are requested. There are no content scripts, broad website access, automatic hover popups, accounts, ads, analytics or stored browsing history. No inspected URLs or results are sent to a server for analysis.

After inspection, choose Open original URL to visit the destination in a new tab. Paths, query parameters and fragments are preserved; embedded credentials are removed. The original URL is handed off in memory and is not stored in the review address. Reloading can discard that link.

Character and brand hints do not establish whether a site is safe or malicious. Heuristic matches can be wrong or incomplete; legitimate internationalized domains also contain non-ASCII characters. No reputation service, TLS certificate lookup, redirect tracing or navigation blocking is used. Chrome’s ordinary address bar is not intercepted or recolored.

English and Simplified Chinese. Requires Chrome 127 or later.
