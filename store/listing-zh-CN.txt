名称
URL Loupe · URL 放大镜

简短说明
本地检查域名中的非 ASCII 与视觉相似字符，支持右键链接检查、工具栏和 host + Tab 地址栏入口。

详细介绍
放大网址里的细微差别。

URL Loupe 帮你逐字符核对域名，标记所有非 ASCII 字符，并提供 I/l、rn/m 等视觉相似字符与组合提示。

三种检查入口：
• 右键链接、选中的网址或页面，选择“使用 URL Loupe 检查”，直接在工具栏插件弹窗查看结果，保持原网页不变。链接按真实目标检查，即使显示文字不同，也不会自动访问目标网站。
• 点击工具栏图标，检查当前页面，或粘贴网址即时检查。
• 在 Chrome 地址栏输入 host 后按 Tab，再输入网址；按回车打开本地高亮检查页。

粉色标记非 ASCII 字符，金框提示视觉相似字符；可查看 Unicode 码点、实际 ASCII/Punycode 域名，以及规范化前的原始 host。

分析在本地完成，不自动访问待检查网站，不向服务器发送网址或结果。没有账号、广告、统计或浏览历史存储，代码与 Unicode 映射随插件打包。支持英文和简体中文，面板可切换语言。

字符提示用于辅助阅读，不构成钓鱼或恶意判定。普通英文与合法国际化域名也可能高亮。本插件版本不比较公司品牌、不查询信誉名单或证书、不追踪跳转、不阻止访问。不会拦截或改色 Chrome 普通地址栏；浏览器内部页、受限页面、PDF 和 iframe 内链接等可能无法检查。

已知域名匹配：与随包参考库中的完整 host 精确一致时，隐藏普通 ASCII 相似字符提示。此规则不构成安全白名单，非 ASCII 输入仍会标记；不会自动放行未收录子域或相似拼写。

随包参考表包含 6,890 个唯一 host，由现有记录与 Google CrUX 2026-09 Top 5000 origin 分组提取的域名合并。CrUX 数据依 CC BY 4.0 保留署名。本项目独立维护，不代表 Google 产品、认可或安全认证。

精简结果默认只显示域名和检查状态；通过项用绿色表示，发现字符问题时再显示解释。ASCII/Punycode、码点与使用帮助可展开查看。参考库未收录的域名显示中性状态。

检查后可点击“打开原网址”，在新标签页访问原目标，保留路径、参数与片段，移除内嵌账号密码。原网址仅在内存中一次性传递，不写入检查页地址；刷新检查页可能丢失原链接。

需要 Chrome 127 或更新版本。

仅使用 activeTab 和 contextMenus 权限，不申请全站网站访问，不注入网页内容脚本，不提供自动悬停检查。
