名称
URL Loupe · URL 放大镜

简短说明
本地检查非 ASCII 域名字符与品牌仿冒线索，突出实际差异；支持右键检查、工具栏和 host + Tab。

详细介绍
放大网址里的细微差别。

URL Loupe 解释域名中值得核对的片段：所有非 ASCII 字符都会标记；与参考品牌相似时，只突出实际差异，例如 rn 替代 m、后缀不同。普通英文字母不会仅因存在形似可能就逐字高亮。

三种检查入口：
• 右键链接、选中的网址或页面，选择“使用 URL Loupe 检查”。原生工具栏弹窗直接展示结果，保留当前网页，检查真实链接目标。
• 点击工具栏图标检查当前页面，或粘贴网址即时检查。省略协议的域名也支持。
• 地址栏输入 host 后按 Tab，再输入网址；回车打开本地检查页。

粉色标记非 ASCII 字符，金色标记品牌差异。悬停、聚焦或点击标记字符可突出对应解释；展开检查详情可查看实际 ASCII/Punycode 和字符信息。

随包参考表包含 6,890 个完整 host；品牌比较覆盖 671 家公司与人工补充品牌。Google CrUX 2026-09 Top 5000 origin 分组仅补充精确匹配，不新增针对全部 CrUX 域名的模糊品牌比较。CrUX 数据依 CC BY 4.0 保留署名，本项目独立维护，不代表 Google 认可或认证。

全部分析在浏览器本地完成，仅申请 activeTab、contextMenus 两项权限。没有网页内容脚本、全站访问权限、自动悬停浮层、账号、广告、统计或浏览历史存储；不向服务器发送网址或结果用于分析。

检查后可主动点击“打开原网址”，在新标签页打开原目标，保留路径、参数与片段，移除内嵌账号密码。完整目标仅在内存中传递，不写入检查页地址；刷新可能丢失原目标。

字符和品牌提示不构成安全或恶意判定，启发式比较可能误报或漏报；合法国际化域名也会包含非 ASCII 字符。不查询线上信誉、证书或跳转链，不阻止导航，也不改色 Chrome 原生地址栏。

支持英文和简体中文，需要 Chrome 127 或更新版本。
