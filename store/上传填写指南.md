版本：0.3.0。此包用于手动上传，尚未向商店提交或通过审核。

## 文件怎么用

上传 `url-loupe-chrome-0.3.0.zip`，其中 manifest.json 位于根目录。不要把整份项目源码 ZIP 或包含本指南的材料 ZIP 当成插件上传。

商品名称与简短介绍由 `_locales/en`、`_locales/zh_CN` 的 manifest 文案提供。默认英文；商店英文介绍复制 listing-en.txt，简体中文本地化复制 listing-zh-CN.txt。

## Privacy practices：可直接复制的英文

Single purpose:
Help users inspect hostname characters for non-ASCII text and visual lookalikes, using a local popup, link-hover overlay and opt-in omnibox review.

activeTab justification:
Read the current tab URL only after the user clicks the extension action, then display a local hostname inspection. No browsing history is collected, stored or transmitted.

Host access / content script justification:
HTTP(S) content scripts listen for link hover and keyboard-focus events so users can inspect a link destination before opening it. The extension reads the relevant anchor href and base URL, analyzes the hostname locally and displays an overlay. It does not crawl all links, collect page text or form fields, alter links, intercept clicks or transmit inspected URLs.

Omnibox justification (if requested):
The host keyword lets users explicitly opt into local URL-character inspection in the address bar. Pressing Enter opens an extension-local review containing only the extracted hostname, not the inspected destination.

Remote code:
No, I am not using remote code. All executable JavaScript, Punycode code and Unicode mapping data are included in the extension ZIP. There are no runtime remote code downloads or eval-based execution.

Data use:
The extension processes URLs locally to extract hostnames but does not collect or transmit user data to the developer or third parties. No extension-side persistent storage, analytics, advertising or browsing history storage is used. Explicitly opening a policy or support link is a normal browser navigation and is described separately in the privacy policy.

当前实现可选择“不收集用户数据”：上述类别均不对外收集／传输。不要误写“无法读取网址”；插件确实在本地处理用户输入、当前标签页网址和链接 href。若控制台对“收集”的字段说明发生变化，以其定义和当前实际行为为准，并保持披露一致。

仅在这些声明与实际行为一致时勾选数据使用认证：不销售或转移数据供无关用途；不用于单一用途以外的目的；不用于信用评估或借贷。插件目前确实不执行这些行为。

## 给审核员的测试说明（英文）

No account, login, payment or API key is required.
1. Open the toolbar popup and choose the Cyrillic example. Non-ASCII characters are highlighted and the Punycode host is shown.
2. Paste https://例子.test — both Chinese hostname characters must be highlighted. Paste https://safe.test/中文?x=а — Unicode path/query characters must not produce a non-ASCII hostname warning.
3. In the address bar type host and press Tab. Enter https://Inkd.test and press Enter. An extension-local review opens; the destination must not be visited.
4. On an ordinary HTTP(S) webpage hover or keyboard-focus a link containing similar hostname characters. An overlay appears. Escape dismisses it; the original link is unchanged. If Chrome restricts a page, use another ordinary webpage or a local HTTP fixture.
5. In the popup switch English / 中文. The input hostname and highlighted characters must remain unchanged.

This build provides character inspection only. It does not include the separate website’s company-reference matching. Highlights do not certify a URL as safe or malicious.
